drawn as one newspaper page: 3 big illustrated heroes, 12 illustrated medium
cards, a proper UTC timeline, region chips, a fields taxonomy, a small
numbered world map, 33 more stories, and a date check.

- **Top story:** Trump unveils new tariffs on 14 economies (USTR).
- **Markets:** Chip stocks crash — KOSPI −6.2%, closes at 4,697.51.
- **Space:** First Pakistani astronaut reaches Tiangong aboard Shenzhou-24.

Built with `build.py` (PIL, deterministic, no network). `main.py` copies the
pre-built `entry.png` to the output directory.
